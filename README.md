## 🎯 Dream Numbers

**Dream Numbers** é um gerador de números aleatórios focado na **Mega-Sena**.

Com ele, é possível:

- 🎲 Definir a **quantidade de jogos** a serem gerados  
- 🔢 Escolher a **quantidade de números** em cada jogo  
- 📈 Ter os números **organizados automaticamente em ordem crescente**

O objetivo é facilitar a criação de apostas de forma rápida, prática e organizada.
